Login styling and artwork are adapted from the
[official Haven site](https://github.com/hackclub/haven/tree/52bd80944fa76f896c728976a5346bffee3870d5):
`Hero.svelte` (logo lockup and forest scene), `SignupForm.svelte` (action),
and `app.css` (type, palette, panel, and frame). The login components are
React ports and use this project's Attend API.

The images and Jua Extras font come from that source tree. Darumadrop One
and Jua are the Latin WOFF2 subsets served by the Sydney page. Font licenses
are included here; Jua Extras combines Jua and Nunito glyphs.
